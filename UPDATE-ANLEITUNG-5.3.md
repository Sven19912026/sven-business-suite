# Sven Business Suite 5.3

## Änderungen

- Aufgaben sind jetzt einzeln ein- und ausklappbar.
- Eingeklappte Aufgaben zeigen eine Notizvorschau mit erhaltenen Zeilenumbrüchen.
- Beschreibungen und Notizen umbrechen auf Mobilgeräten ohne seitliches Scrollen.
- Fälligkeitsdaten enthalten den Wochentag.
- Die Verhandlungsübersicht nutzt am PC die verfügbare Breite besser aus.
- Die Verhandlungstabelle verwendet ein kompaktes, festes Spaltenlayout ohne horizontalen Regler.

## Prüfung

```bash
npm install
npm run lint
npm run build
```
